---
name: interface-motion
description: Add purposeful transitions and interaction feedback to React interfaces.
---

Identify the state change the user needs to follow, such as a selected tab moving or a details panel expanding. Drive the animation from the component's actual state. Keep input and focus responsive while transitions run.

Prefer CSS transforms and opacity for short transitions. Handle interrupted or reversed interactions and provide a prefers-reduced-motion treatment that communicates the final state immediately. Exercise rapid clicks, keyboard activation, and reduced motion.
