---
name: futuristic-ui
description: Design a cohesive futuristic visual treatment for an existing page or a new web experience.
---

Inspect the surrounding typography and theme in frontend/src/index.css. Pick a visual motif that fits the brief, such as crisp illuminated edges around the active workspace. Define reusable surface, text, border, and accent colors. Reserve the strongest contrast for the content and primary action.

Build depth through layering and spacing. If using translucent panels, supply a solid fallback and check text against the brightest background behind them. Inspect the composition at phone and desktop widths with realistic content and visible keyboard focus.
