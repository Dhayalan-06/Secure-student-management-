---
name: tailwind-dashboard
description: Build responsive Tailwind dashboards for comparing records, filtering lists, and taking action on results.
---

Start from the decision the dashboard supports. Give the most useful table or chart enough space to answer it. Derive counts from the same dataset and filter scope as the detail view, or label their scope explicitly.

Use the Tailwind setup and shared styles already in frontend. Keep table headings associated with values. On narrow screens preserve the identifying column and row action, and allow a wide comparison table to scroll inside its own region. Check long names, zero matches, and a filter reset.
